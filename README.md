# Lost & Found — Design Brief

Responsive static web app based on the supplied Week 01 design reference.

## Files
- `index.html` — page structure
- `style.css` — responsive visual design
- `app.js` — draw/reset interactions and localStorage
- `netlify.toml` — Netlify configuration

## Run locally
Open `index.html` in a browser.

## Deploy to Netlify
1. Go to Netlify.
2. Choose **Add new project → Deploy manually**.
3. Upload this project folder.
4. Netlify will publish the site and provide a live URL.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload all four project files.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish.
